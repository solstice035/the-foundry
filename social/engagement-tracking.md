## Instructions

During the manual posting phase, track every post here. This data will:
1. Identify which content types and angles resonate
2. Inform Content Drafter automation
3. Update voice guide based on real performance
4. Guide platform prioritization

**How to use:**
- Add each post immediately after publishing
- Update engagement metrics at 24h, 48h, 7d
- Document qualitative feedback in Notes
- Review weekly to identify patterns

---

## Metrics Definitions

### Quantitative Metrics

| Metric | X/Twitter | Reddit | LinkedIn | HN |
|--------|-----------|--------|----------|-----|
| **Reach** | Impressions | Views (if available) | Views | Views |
| **Engagement** | Likes + Retweets + Replies | Upvotes | Likes + Comments | Points |
| **Shares** | Retweets | Crossposts | Shares | N/A |
| **Comments** | Replies | Comments | Comments | Comments |
| **Clicks** | Link clicks (analytics) | Link clicks | Link clicks | Link clicks |
| **Saves** | Bookmarks | Saves (if visible) | N/A | N/A |

### Qualitative Metrics

- **Sentiment:** Positive / Neutral / Negative / Mixed
- **Notable mentions:** Accounts with >10K followers engaging
- **Question quality:** Genuine technical questions vs generic
- **Feature requests:** Concrete asks from users
- **Competitive mentions:** Other tools mentioned in comments

## Engagement Rate Calculation

**X/Twitter:**
```
Engagement Rate = (Likes + Retweets + Replies + Bookmarks) / Impressions * 100
```

**Reddit:**
```
Engagement Rate = (Upvotes / Views) * 100
Note: Views often not visible, use upvotes as primary metric
```

**LinkedIn:**
```
Engagement Rate = (Likes + Comments + Shares) / Views * 100
```

**HN:**
```
Engagement Rate = Points / Views * 100
Note: Views not public, use points + comments as primary metric
```

## Testing Phase Completion Criteria

**Epic 3.1 is complete when:**

- [ ] 4-6 posts published manually across content types
- [ ] Each content type tested at least once
- [ ] Engagement tracked for minimum 7 days per post
- [ ] Patterns identified (what works, what doesn't)
- [ ] Voice guide updated based on real learnings
- [ ] Baseline metrics established for each platform
- [ ] At least one high-performer identified
- [ ] At least one underperformer analyzed
- [ ] Posting templates validated or revised

**Readiness for Epic 3.2 (Content Drafter automation):**

- [ ] >60% of manual posts would be "approved as-is" in hindsight
- [ ] Clear patterns documented
- [ ] Voice guide refined with real examples
- [ ] Platform timing validated
- [ ] Template effectiveness confirmed
